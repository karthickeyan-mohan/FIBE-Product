# Faisal Islamic Bank of Egypt — digital banking (web)

Retail and business digital banking for Faisal Islamic Bank of Egypt: accounts, transfers, bill payments (Fawry), cards, personal finance, service requests, settings and business banking, in English and Arabic, light and dark, on mobile, tablet and desktop.

## What to upload

Only these two files, at the top of the repository (or of the folder you publish):

| File | What it is |
|---|---|
| `index.html` | The whole app in one file: styles, scripts, fonts, icons, flags, card art and biller logos are all built in. Nothing else is needed. |
| `README.md` | This file. |

## Make it live with GitHub Pages

1. Create a repository on GitHub (public, or private on a plan that allows Pages).
2. Upload `index.html` and `README.md` to the main branch (Add file → Upload files → Commit).
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute or two the site is live at `https://<your-account>.github.io/<repository>/`.

To put the web app and the watch app in one repository instead, upload them as two folders (`fibe/index.html` and `watch/index.html`); they are then live at `…/<repository>/fibe/` and `…/<repository>/watch/`.

## How it runs

- It works on its own: no server, build step or backend is needed. It runs on built-in demo data (mock mode), so every screen and journey can be tried.
- Any static host works the same way (GitHub Pages, Netlify, an S3 bucket…). It also opens straight from the file on a computer.
- Language, theme and similar preferences are kept in the browser on each device.

## Test values (demo data)

| What | Value |
|---|---|
| Log in | any User ID of 8–32 letters or digits and any password |
| OTP (SMS / email) and soft token | **000000** |
| mPIN (quick login) | **4826** — open with `?device=trusted` to have quick login set up |
| Current password (Change password) | **Secret@123** |
| Card PIN (Show card details, Change PIN) | **0000** |

Open straight into the app (already signed in): `index.html?device=trusted&auth=1#/home`
